# Learning Contact Representation for Leg Odometry

Research project on learning contact-state representations for contact-aware legged odometry.

> [!IMPORTANT]
> This repository is currently a publication placeholder. Source code, trained weights, datasets, and runnable examples have not yet been released.

## Intended scope

- Learn contact representations from proprioceptive robot data.
- Infer stance/contact states for leg-odometry updates.
- Compare learned representations with analytical contact detectors.
- Evaluate the effect of contact uncertainty on state estimation.

## Related implementation

For the lab's currently available contact detectors, feature preprocessing, model-training code, and error-state EKF pipeline, see [leg-odometry-framework](https://github.com/srge-erau/leg-odometry-framework).
